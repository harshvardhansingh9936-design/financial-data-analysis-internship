# Financial Data Analysis Internship

## Overview

This repository contains my work for a financial analytics internship,
including data acquisition, data cleaning, exploratory data analysis,
visualization, and documentation using Python.

## Project Objectives

- Acquire publicly available financial data
- Validate and clean datasets
- Perform preliminary exploratory analysis
- Analyze market trends and volatility
- Examine relationships between market and macroeconomic variables
- Build a reproducible Python workflow

## Data Sources

- Federal Reserve Bank of St. Louis (FRED)
- Yahoo Finance / yfinance

## Technologies

- Python
- pandas
- NumPy
- matplotlib
- seaborn
- yfinance
